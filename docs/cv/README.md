## Ghi chú

- `uiux.pdf` và `uiux-c-bi.pdf` là hai file khác nhau nhưng nội dung chữ giống hệt nhau.
- File `.md` được trích tự động từ PDF ngày 2026-11-26. Ở các CV dàn hai cột, ngày tháng có thể nằm lệch dòng so với mục của nó. Bản PDF là bản chuẩn.
- Khi sửa CV: cập nhật PDF, rồi sửa file `.md` tương ứng cho khớp.
- Nội dung CV nào đã được đưa lên site: xem [../CV-SOURCE-MAP.md](../CV-SOURCE-MAP.md).
