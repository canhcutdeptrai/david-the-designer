# Extend the portfolio kit

1. Kiểm tra token và component hiện có trước khi thêm mới.
2. Component mới phải có semantic HTML, keyboard behavior, focus và trạng thái disabled/error khi phù hợp.
3. CSS mới dùng token trong `theme.css`; không thêm màu hardcode ngoài file theme.
4. Viết demo trung tính, không gắn tổ chức hoặc nghiệp vụ cụ thể.
5. Cập nhật tài liệu ngắn và validation khi thêm convention mới.
6. Kiểm render trước khi báo hoàn tất.
