# Minimal API map

| HTML | Angular concept |
|---|---|
| `sd-button` | Button component với input title/icon/type |
| `sd-badge` | Badge component với label/color/icon |
| `sd-input` / `sd-textarea` | Form control + label/error |
| `sd-section` | Section/card component |
| `sd-tab-group` | Accessible tabs |
| `sd-modal` / `sd-side-drawer` | Overlay service/component |

Tên input/output phải được xác nhận theo đúng package version của ứng dụng đích.
