Nút tròn dưới thẻ để thu gọn / mở nhánh.

Chỉ có title → thẻ compact; color tô nền thẻ; "Phòng Kế toán" khai expanded: false. Dữ liệu truyền qua option = { items, onToggle }.

Không có nút thu gọn, luôn mở hết (bỏ qua cả expanded: false).

itemTemplate là hàm nhận { item, depth, parent, expanded, hasChildren, isLeaf } và trả về HTML nội dung thẻ; khung thẻ, màu nền, đường nối, nút thu gọn vẫn của component.

option.onToggle({ item, expanded }) và event kebab sd-toggle.

Chưa có sự kiện nào.
check_circle Dùng khi
  • Thể hiện cơ cấu tổ chức: khối → phòng → bộ phận, hoặc cấp quản lý → nhân sự
  • Sơ đồ phân cấp phê duyệt / uỷ quyền cần nhìn tổng thể theo chiều dọc
  • Số tầng vừa phải (2–4 tầng), mỗi tầng không quá nhiều nhánh
cancel Không dùng khi
  • Cây sâu, nhiều nút, cần chọn / tìm kiếm — dùng sd-tree
  • Dữ liệu là danh sách phẳng có cột thông tin — dùng sd-table
  • Quy trình có thứ tự bước — dùng sd-stepper

Cách mô tả trong PRD / giao cho AI

"Tab Cơ cấu tổ chức hiển thị sd-org-chart: gốc là Khối Tài chính (nền #f5eee6), dưới là các phòng, dưới nữa là bộ phận. Phòng Kế toán thu gọn sẵn. Mỗi thẻ chỉ có tên đơn vị."

Cú pháp

HTML 
<sd-org-chart id="so-do" autoId="co-cau"></sd-org-chart>

<script>
  // SdOrgChartItem: { id, title, description?, image?, color?, expanded?, children? }
  document.getElementById('so-do').items = [{
    id: 'cfo', title: 'Nguyễn Văn An', description: 'Giám đốc Tài chính', image: '/assets/avatar/an.png',
    children: [
      { id: 'kt', title: 'Hoàng Thu Hà', description: 'Kế toán trưởng' },
      { id: 'p2', title: 'Phòng Kế toán', expanded: false, children: [ … ] }
    ]
  }];

  // hoặc gom vào option (option.* thắng input rời)
  el.option = { items: units, collapsible: true, onToggle: function (e) { /* e.item, e.expanded */ } };

  // thẻ tuỳ biến (≙ <ng-template sdOrgChartItemDef let-item let-depth="depth">)
  el.itemTemplate = function (ctx) { return '<div class="sd-org-chart__title">' + ctx.item.title + '</div>'; };
</script>
