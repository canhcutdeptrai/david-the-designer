Cú pháp của thư viện: properties.visibleWhenExpression / hiddenWhenExpression / requiredWhenExpression / disabledWhenExpression là JSON { field, operator, value } (EQUAL · NOT_EQUAL · GREATER_THAN · LESS_THAN · GREATER_OR_EQUAL · LESS_OR_EQUAL · NULL · NOT_NULL) hoặc nhóm { type: 'combinator', combinator: '&&' | '||', conditions }. Đổi lựa chọn bên dưới — sau 500ms (debounce của thư viện) form tính lại.
