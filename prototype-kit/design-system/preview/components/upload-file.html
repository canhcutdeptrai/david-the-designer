description tự sinh: "Định dạng: {exts} và tối đa: {maxSize}MB"; lỗi required hiện sau khi touched.

Không truyền description thì component tự sinh dòng mô tả từ extensions + maxSize — đúng 3 nhánh của thư viện: "Định dạng: … và tối đa: …MB" / "Định dạng: …" / "Tối đa: …MB".

Di chuột lên thumbnail để hiện nút phóng to; nút close góc trên phải để xoá (có hộp thoại xác nhận). Kéo thả thumbnail để đổi thứ tự.

disabled — còn ảnh vượt maxOfImage thì ô cuối hiện overlay "+N"

required chưa upload — message lỗi role="alert"

helperText — icon info_outline cạnh nhãn, rê chuột xem gợi ý

previewWidth/Height = 80px

align="center"
check_circle Dùng khi
  • Upload file đính kèm (hợp đồng, hình ảnh sản phẩm, chứng từ)
  • Import dữ liệu từ Excel/CSV
  • Cần chặn dung lượng hoặc định dạng file ngay trên form
  • Cần xem trước ảnh và sắp xếp lại thứ tự ảnh

  • Chụp ảnh từ camera (thư viện chưa hỗ trợ)
  • Upload cả thư mục hoặc file rất lớn cần chia mảnh (resumable)
  • Chỉ để hiển thị file đã có mà không cho sửa — dùng link/preview

typeNghĩaKhi nào chọn

documentChuyên tài liệuHợp đồng, biểu mẫu, file Excel

type chỉ chặn ảnh/không ảnh. Muốn khoá đúng đuôi file thì phải liệt kê extensions — hai thứ độc lập nhau.

Cách mô tả trong PRD / giao cho AI

"Form yêu cầu đính kèm tối đa 3 file PDF hoặc ảnh, mỗi file ≤ 5MB, trường bắt buộc."

"Màn chi tiết hiển thị tối đa 3 ảnh đã duyệt, còn lại gộp thành +N, không cho sửa."

Điều cần chốt với Dev

  • File lưu ở đâu — component chỉ giữ id/key do backend trả về, không giữ file.
  • Tải file về đi qua API có xác thực hay mở thẳng URL CDN.
  • Số file tối đa (max) và số ảnh hiển thị khi xem (maxOfImage).

Cú pháp — prototype (Web Component)

HTML 
<sd-upload-file label="Đính kèm tài liệu" type="document"
                extensions="pdf,doc,docx,xlsx" maxSize="5" max="3" required></sd-upload-file>

Cú pháp — Angular (@sdcorejs/angular)

HTML 
<sd-upload-file
  [label]="'Đính kèm tài liệu'"
  [type]="'document'"
  [extensions]="['pdf', 'doc', 'docx', 'xlsx']"
  [maxSize]="5"
  [max]="3"
  [required]="true"
  [upload]="uploadFn"
  [details]="detailsFn"
  [(model)]="files">
</sd-upload-file>

model là mảng id/key, không phải mảng File. Trước khi submit phải gọi uploadRef.upload() để đẩy file lên và lấy key.

Nạp file đã có (màn Read / Edit)

JS 
var el = document.getElementById('uf-docs');
el.details = async function (keys) {
  return keys.map(function (k) {
    return { idOrKey: k, cdn: '/api/file/' + k, name: 'hop-dong.pdf', extension: 'pdf', size: 1.2 };
  });
};
el.model = ['file-001'];

Prototype không có attribute kiểu files="..." — thư viện thật không có, thêm vào sẽ lệch mirror. Nạp sẵn file luôn đi qua cặp details + model.

Khác biệt có chủ ý giữa mirror và thư viện

  • Icon theo AGENTS Rule 4 dùng bộ outlined (catalog: material-icons cho close / info_outline) — nét giống hệt.
