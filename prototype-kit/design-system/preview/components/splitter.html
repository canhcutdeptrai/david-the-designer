Cú pháp

HTML 
<sd-splitter orientation="horizontal">
  <sd-splitter-panel panelId="sidebar" size="250" unit="px" minSize="100" maxSize="400" collapsible>...</sd-splitter-panel>
  <sd-splitter-panel size="1">...</sd-splitter-panel>
</sd-splitter>

Attributes - sd-splitter

AttributeGiá trịMặc địnhMô tả
orientationhorizontal, verticalhorizontalHướng chia panel
snapThresholdnumber - ví dụ 0.4-Kéo panel collapsible xuống dưới 40% min thì snap collapse
storageKeystring-Khoá localStorage - refresh giữ nguyên layout; panel phải có panelId mới được lưu
disabledbooleanfalseVô hiệu hoá toàn bộ thao tác kéo/gập

Attributes - sd-splitter-panel

AttributeGiá trịMặc địnhMô tả
panelIdstring-Định danh panel - dùng cho method và localStorage
sizenumber-Kích thước - nghĩa phụ thuộc unit
unitpx hoặc bỏ trốngbỏ trống (flex)px = kích thước cố định; bỏ trống = phần flex theo size
minSizenumber-Nhỏ nhất - flex là tỉ lệ (0.2, 0.3), px là số px
maxSizenumber-Lớn nhất - cùng quy ước minSize
collapsiblebooleanfalseCho gập; double-click handle để bật/tắt
resizablebooleantrueresizable="false" (chuỗi) thì 2 handle kề bị vô hiệu

Events

EventdetailKhi nào fire

Methods (trên phần tử sd-splitter)

MethodMô tả

resizePanel(panelId, px)Đặt kích thước panel theo px
expand(panelId)Mở panel đang gập
resetLayout()Khôi phục layout theo size đã khai, xoá dữ liệu đã lưu

Ghi chú

sd-splitter cần được bọc trong parent có chiều cao cụ thể. Nội dung panel giữ nguyên node DOM - event listener gắn bên trong panel vẫn sống, splitter lồng nhau chạy bình thường.
