Chạy thật: khung nét đứt tải về Mau_import_khoan_vay.xlsx; điền dữ liệu từ dòng 3 rồi bấm Tải lên để đọc file, kiểm tra từng ô theo cấu hình cột và xem trước.

Dữ liệu mẫu nạp bằng setData() (như vừa đọc từ file). Bấm các nút đếm để lọc; rê chuột ô đỏ để xem lỗi; còn dòng lỗi thì “Xác nhận & Lưu” vô hiệu. “Tải về” xuất file Excel kèm cột Thông báo.

Cột kiểu array mở danh sách qua mat-menu. “Xác nhận & Lưu” gọi option.accept(items, { file }).

 
Chưa có sự kiện nào.
check_circle Dùng khi
  • Nhập hàng loạt bản ghi từ file Excel theo mẫu cố định (khoản vay, nhân sự, danh mục…)
  • Cần người dùng xem trước và sửa file trước khi lưu — mỗi ô được kiểm tra (bắt buộc, số, ngày, danh sách giá trị, độ dài)
  • Server kiểm tra thêm sau khi lưu và trả lỗi từng dòng (setValidation)
cancel Không dùng khi
  • Chỉ đính kèm file để lưu trữ — dùng sd-upload-file
  • Nhập vài dòng — dùng form hoặc bảng nhập tay

Hành vi cần biết

  • File mẫu: dòng 1 là mã cột (đỏ nếu bắt buộc), dòng 2 là tên cột, dòng 3 là mô tả nếu có cột khai description; dữ liệu đọc từ dòng kế tiếp. Số thứ tự trong bảng là số dòng trong Excel.
  • Tối đa limit dòng (mặc định 1000); file rỗng / quá giới hạn → thông báo cảnh báo, không mở bảng.
  • Cảnh báo vẫn cho lưu; còn một dòng lỗi thì không. Đã bấm “Xác nhận & Lưu” thì nút khoá tới lần tải file sau.
  • Bảng phân trang 50 dòng (mat-paginator, nhãn tiếng Anh “1 – 50 of 60” như catalog).
