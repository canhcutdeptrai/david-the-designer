Dữ liệu, cấu hình và trạng thái chép nguyên từ catalog Core UI (portal-fins). Ba popup — chip popover (biến thể 2), field picker (biến thể 3) và bộ lọc đã lưu (biến thể 6) — bấm vào chip / nút + / nút bookmark để mở; đóng (bấm ra ngoài hoặc Esc) là commit.

Popover mode (mặc định) — ô tìm kiếm · 3 chip đang lọc + 1 chip chưa có giá trị · AND/OR · xoá tất cả · bộ lọc đã lưu · tìm kiếm

Chip popover — field number, operators: true, BETWEEN (bấm chip “Số tiền giải ngân”)

Field picker (nút “+”) — field đã dùng bị mờ kèm dấu check

Inline mode (GitLab-style) — chip string/number là ô nhập liền · chip values · chip đang build (dashed)

density="comfortable" + showOperatorOnChip — chip 32px (compact: 28px) · icon operator thay “:” · logic OR → “OR” giữa chip

Bộ lọc đã lưu — localStorage “sd-query-bar:savedFilters:fins-ho-so-giai-ngan”; chọn dòng → nạp lại + sd-apply

Click chip để mở popover chỉnh operator + value. Phía dưới hiện shape filters đúng như Portal: {field, operator, data}.

var bar = document.getElementById('qb-seven');
bar.fields = [
  { type: 'lazy-values', key: 'city', label: 'Thành phố (lazy)',
    operators: ['IN','NOT_IN'],
    option: { search: api.searchCities, valueField: 'value', displayField: 'display' } }
];
bar.filters = [{ field: 'city', operator: 'IN', data: ['HN','HCM'] }];
bar.addEventListener('sd-apply', function (e) { callApi(e.detail); });
bar.addEventListener('sd-filters-change', function (e) { applyFilters(e.detail.filters); });

Quan hệ với pattern filter-bar

              

                
sd-query-bar là component của thư viện thật (@sdcorejs/angular) - chip row động, field config, 2-way filters, popover/inline. filter-bar là pattern riêng của kit (data-pattern) - khung "Bộ lọc" mở/đóng với grid cố định, PD kiểm soát HTML. Khi prototype có sẵn pattern filter-bar hoặc BA mô tả theo layout khung lọc thì giữ pattern; khi cần chip lọc động nhiều field với payload chuẩn thì dùng sd-query-bar.
