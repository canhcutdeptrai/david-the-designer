Tên ngân hàng

sd-change ≙ (modelChange) của [(model)] — chỉ phát khi đổi sang toán tử khác.

Chưa có sự kiện nào.
check_circle Dùng khi
  • Ô lọc cần cho người dùng chọn cách so sánh: bằng, lớn hơn, trong khoảng, chứa…
  • Dựng điều kiện trong sd-query-bar / sd-query-builder (hai component này đã dùng sẵn)
  • Chỉ cho phép một số toán tử theo kiểu dữ liệu (số tiền, chuỗi, ngày)
cancel Không dùng khi
  • Ô lọc luôn so sánh một kiểu cố định — không cần cho chọn
  • Chọn giá trị dữ liệu (trạng thái, chi nhánh) — dùng sd-select
  • Bộ lọc nhiều điều kiện lồng nhau — dùng sd-query-builder

Cách mô tả trong PRD / giao cho AI

"Cạnh ô Số tiền giải ngân có sd-operator cho chọn: Bằng, Không bằng, Lớn hơn, Nhỏ hơn, Lớn hơn hoặc bằng, Nhỏ hơn hoặc bằng, Trong khoảng — mặc định Lớn hơn hoặc bằng. Chọn Trong khoảng thì ô nhập đổi thành hai ô Từ / Đến."

Cú pháp

HTML 
<sd-operator id="op-so-tien" model="GREATER_OR_EQUAL" autoId="loc-so-tien"
  operators='["EQUAL","NOT_EQUAL","GREATER_THAN","LESS_THAN","GREATER_OR_EQUAL","LESS_OR_EQUAL","BETWEEN"]'></sd-operator>

<script>
  var op = document.getElementById('op-so-tien');
  op.addEventListener('sd-change', function (e) { /* e.detail.value */ });
  op.open();    // mở menu bằng code (như sd-query-bar khi dựng điều kiện)
</script>
