Chưa có sự kiện nào.

Catalog xếp sd-ckeditor-styles là một mục riêng nhưng nó không render gì: việc duy nhất là nạp một lần stylesheet global của CKEditor 5 (nguyên văn SdCKEditorStyles) vào <head> khi editor đầu tiên được mount. Catalog không vẽ thẻ đó trong cây DOM → <sd-mini-editor> của kit gọi thẳng hàm nạp; thẻ <sd-ckeditor-styles> vẫn dùng được ở chỗ khác. Vì không có giao diện nên nó không có trang preview riêng.

Đã nạp vào <head>: —
check_circle Dùng khi
  • Ô bình luận / ghi chú ngắn cần định dạng nhẹ: đậm, nghiêng, gạch chân, màu chữ, danh sách, liên kết
  • Cần nhắc tên đồng nghiệp bằng @ (mention) để gửi thông báo
  • Ghi chú lưu dạng Markdown (outputFormat: 'markdown')
cancel Không dùng khi
  • Trường form có nhãn, bắt buộc, giới hạn ký tự, cỡ chữ / căn lề / ảnh — dùng sd-editor
  • Soạn văn bản dài theo mẫu (hợp đồng, tờ trình) — dùng sd-document-builder
  • Chỉ cần chữ thuần — dùng sd-textarea

Cách mô tả trong PRD / giao cho AI

"Cuối tab Thảo luận có sd-mini-editor placeholder 'Viết bình luận cho hồ sơ...', bật mention @ với danh sách cán bộ thẩm định; chọn tên thì thêm vào danh sách người nhận thông báo. Hồ sơ đã phê duyệt thì editor disabled."

Cú pháp

HTML 
<sd-mini-editor id="binh-luan"><p>Nội dung ban đầu (≙ ngModel)</p></sd-mini-editor>

<script>
  var ed = document.getElementById('binh-luan');
  ed.option = {
    placeholder: 'Viết bình luận cho hồ sơ...',
    enableMention: true,
    mentionConfig: {
      feeds: [{ marker: '@', feed: searchUsers, minimumCharacters: 1 }]   // feed CKEditor: [{ id: '@...', text }]
    },
    onMentionSelect: function (item) { taggedUsers.push(item); }
  };
  ed.addEventListener('sd-change', function (e) { /* e.detail.value — HTML hoặc Markdown */ });
</script>

Đóng gói

CKEditor 5 nằm ở design-system/vendor/ckeditor5/ckeditor5.min.js (~1 MB, giấy phép GPL như licenseKey: 'GPL' của thư viện), tự nạp khi trang có <sd-mini-editor>. Đổi chỗ đặt: window.SD_CKEDITOR_BASE = '…/ckeditor5/' trước khi nạp sd-components.js.
