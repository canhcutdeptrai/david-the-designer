variant="browse" — Trang danh sách: title + primary CTA

variant="browse" + page-tabs — Danh sách có tab lọc theo trạng thái

variant="read" — Chi tiết record: title + record ID + badge + primary action

variant="read" + subtitle + page-tabs — Chi tiết có sub title và tab điều hướng

variant="read-approval" — Chi tiết chờ duyệt: ← Quay lại + title + record ID + badge | Lịch sử + Từ chối (light warning) + Duyệt (light success) + Chỉnh sửa (fill)

variant="edit" — Form có approval: Bỏ qua + Lưu nháp + Primary

variant="edit" — Form đơn giản: Bỏ qua + Primary

check_circle Dùng khi
  • Header cho mọi trang OMEU — đây là component bắt buộc
  • Thể hiện title và primary CTA của trang
  • Dùng page-tabs khi trang có nhiều trạng thái hoặc sub-views
cancel Không dùng khi
  • Standalone — page-header luôn đi kèm với page layout, không dùng riêng lẻ

Cách mô tả trong PRD / giao cho AI

"Trang Danh sách Đơn hàng: header có tab lọc Tất cả / Chờ xử lý / Hoàn thành, nút Tạo đơn hàng."

"Trang Chi tiết Nhà cung cấp: header có mã NCC-0042, badge Hoạt động, subtitle ngày cập nhật, nút Chỉnh sửa. Bên dưới có tab: Thông tin chung / Lịch sử / Hợp đồng."

Cú pháp đầy đủ

HTML 
<!-- Browse + page-tabs -->
<div data-pattern="page-header" data-variant="browse"
     data-title="Danh sách đơn hàng"
     data-primary-action="Tạo đơn hàng"
     data-primary-icon="add"
     data-page-tabs="Tất cả,Chờ xử lý,Hoàn thành"></div>

<!-- Read + subtitle + page-tabs -->
<div data-pattern="page-header" data-variant="read"
     data-title="Chi tiết nhà cung cấp"
     data-record-id="#NCC-0042"
     data-badge="Hoạt động" data-badge-status="active"
     data-subtitle="Cập nhật lần cuối: 15/04/2026"
     data-primary-action="Chỉnh sửa"
     data-page-tabs="Thông tin chung,Lịch sử,Hợp đồng"></div>

Code Angular tương ứng (@sd-angular/core — sd-page + pattern Page Header của portal-template, 2026-10-14)

Pattern dựng đúng DOM header của sd-page: div.c-page-header.bg-white > div.p-16.d-flex… với vùng headerLeft / headerRight. Dev viết lại bằng <sd-page> như dưới. Nút "Lịch sử thay đổi", "Bỏ qua", "Lưu nháp" là tác vụ kit giữ lại — portal-template không có. Badge: color / icon lấy theo STATUS_MAP của data-badge-status.
